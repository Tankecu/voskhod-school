# VOSKHOD ✦ — школа поступления в США: сайт + платформа Orbit

**Лендинг:** https://tankecu.github.io/voskhod-school/
**Платформа:** https://tankecu.github.io/voskhod-school/app/
**APK (Android):** https://tankecu.github.io/voskhod-school/app/dist/voskhod-orbit.apk

## Состав репозитория

```
index.html, css/, js/     — лендинг-визитка школы (WebGL-космос, живая траектория)
app/                      — VOSKHOD Orbit 2.0: платформа обучения (PWA + APK)
  js/config.js            — КОНФИГ: ключи Supabase, ссылка на APK, версия
  js/db.js                — слой данных: адаптеры Local / Supabase, хэш паролей, роли
  js/tests-bank.js        — банк тестов на английском (14 тестов, ~100 вопросов)
  js/theory.js            — библиотека теории (SAT Math, R/W, Grammar, TOEFL, Milliy)
  js/app.js               — роутер и экраны (admin / teacher / student)
  js/tests.js             — движок прохождения тестов + конструктор
  js/ui.js, js/cosmos.js  — хелперы и космический фон
  sw.js                   — service worker (офлайн). ПРИ ЛЮБОМ ИЗМЕНЕНИИ app-файлов
                            подними VERSION, иначе кэш перебьёт обновление
  dist/voskhod-orbit.apk  — подписанный Android-APK
apk/                      — исходники APK: манифест, MainActivity, иконки,
                            build-apk.sh (сборка без Gradle), keystore.jks
supabase-schema.sql       — схема базы для Supabase
```

## Платформа: роли и первый запуск

- **Первый запуск** → мастер создания администратора (логин + пароль). Демо-данных нет.
- **Админ** создаёт все аккаунты («Люди» → Создать), управляет группами, журналом оплат
  (месяц / сумма / UZS-USD / нал / Click / Payme / перевод), видит все попытки тестов.
- **Учитель** ведёт расписание своих групп (кнопка «+ Урок»: тема, время, ссылка на класс,
  материалы, домашка), создаёт тесты в конструкторе, видит прогресс учеников.
- **Ученик** видит расписание с преподавателями, домашку, статус оплаты, библиотеку
  теории и 14 тестов на английском; за решения — XP, уровни-орбиты и значки.
- Пароли хранятся **только хэшем** (SHA-256 + соль). Сброс пароля — в «Людях» за один клик.

## Подключить общую базу (Supabase, бесплатно)

По умолчанию данные живут на устройстве (localStorage). Чтобы аккаунты, оплаты и
расписание стали общими для всех устройств:

1. Зарегистрируйся на supabase.com (нужен только email) → New Project
2. SQL Editor → вставь `supabase-schema.sql` → Run
3. Settings → API: скопируй **Project URL** и **anon public key**
4. Вставь их в `app/js/config.js` (SUPABASE_URL и SUPABASE_ANON_KEY)
5. Коммит + пуш — всё, система общая

Ограничение честности: anon-ключ публичный по дизайну Supabase — защита данных
прикладная (роли в приложении), не криптографическая. Для школьного MVP достаточно.

## APK

`app/dist/voskhod-orbit.apk` — подписанный (v2+v3), package `com.voskhod.orbit`,
WebView-обёртка платформы: контент обновляется вместе с сайтом, без пересборки.
Раздавай файлом: ссылка выше или кнопка «APK» на лендинге.

Пересборка: `cd apk && bash build-apk.sh` (нужны JDK и Android build-tools —
скрипт ожидает их распакованными в `/d/rep/apk-build/`; пути внутри скрипта).
Пароль keystore: `voskhod-orbit` (файл `apk/keystore.jks`). ⚠️ Keystore в публичном
репозитории — осознанный компромисс удобства для школьного проекта.

## Обновление платформы

Любой пуш в `main` обновляет и лендинг, и платформу, и контент внутри APK.
Не забудь поднять `VERSION` в `app/sw.js`, если менял app-файлы.
