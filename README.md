# VOSKHOD ✦ — сайт-визитка онлайн-школы

Онлайн-школа поступления в университеты США для абитуриентов из СНГ.
Космический одностраничник: WebGL-космос (звёзды, туманность, метеоры),
живая траектория полёта по скроллу, boot-секвенция «центр управления полётами».

**Живой сайт:** https://<ваш-username>.github.io/voskhod-school/

## Структура

```
index.html      — все секции (hero, полётный план, программы, цифры, отзывы, FAQ, заявка)
css/style.css   — дизайн-система (палитра, типографика, стекломорфизм, адаптив)
js/cosmos.js    — процедурный WebGL-космос (без библиотек)
js/main.js      — траектория по скроллу, счётчики, форма, курсор, магнит-кнопки
favicon.svg
app/            — VOSKHOD Orbit: платформа обучения (PWA: сайт + Android-приложение)
  index.html, manifest.webmanifest, sw.js
  css/app.css   — дизайн-система платформы
  js/db.js      — данные (localStorage, демо-сид); точка пересадки на реальный бэкенд
  js/ui.js      — хелперы (иконки, даты, тосты, модалки)
  js/tests.js   — движок тестов + конструктор для преподавателей
  js/app.js     — роутер и экраны (ученик/преподаватель)
  tools/        — скрипты разработки (иконки, автотесты; node_modules не в репо)
```

## Платформа VOSKHOD Orbit (`/app/`)

PWA — работает как сайт и ставится на Android как приложение
(Chrome → меню → «Установить приложение» или кнопка в разделе «Ещё»).
Вход демо-режима без пароля: «Азиз Каримов» (ученик) или «Елена Смирнова» (преподаватель).
Данные хранятся в localStorage устройства. Для реального бэкенда заменить `js/db.js`
на API-слой (Supabase/Firebase) — интерфейс не меняется.

Зависимостей нет — только шрифты Google Fonts (Unbounded / Manrope / JetBrains Mono,
все с кириллицей). Билд не нужен.

## Что поменять перед реальным запуском

### 1. Контакты (важно!)
В `js/main.js`, самое начало файла, константа:

```js
var CONTACTS = {
  telegram:  'https://t.me/voskhod_placeholder',
  whatsapp:  'https://wa.me/998000000000',
  instagram: 'https://instagram.com/voskhod.placeholder'
};
```

Замените на реальные ссылки — этого достаточно для всех кнопок и формы.

### 2. Цифры и факты
Цифры в секции «Результаты» (320+ студентов, 97%, 1460 SAT, $4.2M) —
**заглушки**. Поменяйте в `index.html`, блок `<section id="results">`
(атрибуты `data-count`, `data-prefix`, `data-suffix`).

### 3. Отзывы
Отзывы Дианы, Тимура и Мадины — **написаны как пример**. Замените на
реальные с согласия студентов, иначе это будет нечестно по отношению
к клиенту и к студентам.

### 4. Цены
В FAQ цена описана без конкретики («посчитаем на диагностике») —
осознанное решение, чтобы не писать цифры от балды. Если нужен блок
с ценами — добавьте карточки в секцию программ.

## Локальный запуск

Просто откройте `index.html` в браузере, или:

```bash
cd voskhod
python -m http.server 8080
# → http://localhost:8080
```

## Как подключить свой домен (необязательно)

1. В настройках репозитория → Pages → Custom domain → впишите домен
2. У регистратора добавьте CNAME-запись: `www → <username>.github.io`
   (или A-записи на GitHub Pages IP: 185.199.108-111.153)
3. Дождитесь DNS-проверки, включите «Enforce HTTPS»

## Деплой

Сайт хостится на **GitHub Pages** (бесплатно, навсегда, с HTTPS).
Любой коммит в `main` автоматически обновляет сайт.
